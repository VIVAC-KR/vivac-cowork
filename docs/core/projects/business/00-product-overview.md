# 제품 개요 — VIVAC

> 대상: 프로덕트 오너, PM, 신규 합류 스태프. 원본: `docs/PRODUCT.md`, `docs/core/projects/PRODUCT.md`(엔지니어링 저장소 사본).
> 개발자 관점 문서는 [`../devel/`](../devel/README.md) 참고.

## 1. 한 줄 정의

> **"당신이 찾던 그 캠핑 스팟, VIVAC에 다 모아뒀습니다."**

캠핑장, 노지, 차박지, 비박지, 자연휴양림 등 흩어진 캠핑 장소 정보를 한데 모아 지도로 탐색하는 서비스.

## 2. 해결하는 문제

| 문제 | 상세 |
|---|---|
| 정보 파편화 | 캠핑 장소 정보가 고캠핑, 산림청, 지자체 사이트, 블로그에 흩어져 있다 |
| 핵심 정보 부재 | 불피움 가능 여부, 입산 통제, 차량 진입 같은 결정적 정보는 공식 채널에서도 찾기 어렵다 |
| 기존 서비스의 사각지대 | 캠핏·땡큐캠핑·고캠핑 등은 예약형 캠핑장 중심이라 노지/차박/비박을 다루지 않는다 |

## 3. 차별화 포인트

| # | 포인트 | 설명 |
|---|---|---|
| 1 | 노지/차박/비박 커버리지 | 비정형 스팟까지 통합 — 경쟁 서비스가 다루지 않는 영역 |
| 2 | 감성 큐레이션 | 사진/분위기 중심의 감도 높은 콘텐츠 |
| 3 | 캠퍼 관점 필터 | 화기, 도보 접근, 식수원 등 실사용 기준으로 필터링 |

## 4. 타겟

- 캠핑에 지출 의향 있는 2030, 캠핑 감성을 추구하는 감도 높은 고객
- 오토캠퍼·차박러 + 백패커/비박커

## 5. 플랫폼

웹 + 모바일, **mobile-first**로 시작.

## 6. MVP 범위

| 기능 | 설명 |
|---|---|
| 지도 기반 탐색 | 주변/지역별 탐색, 유형 필터(캠핑장/노지/차박/비박/휴양림) + 속성 필터 |
| 스팟 상세 | 아래 4대 속성 중심으로 구성 |
| 스팟 저장 + offline 열람 | 저장한 스팟은 인터넷이 안 되는 오지에서도 열람 가능 |

### 4대 핵심 속성

| 속성 | 상세 항목 |
|---|---|
| 화기 | 불피움/화로대/장작 가능 여부, 허용 범위 |
| 접근성 | 차박 가능 여부, 진입로 상태(비포장/4WD), 주차, 도보/대중교통 |
| 편의시설 | 화장실, 개수대, 식수원, 전기, 샤워실, 매점 거리 |
| 예약/요금 | 예약 방법, 외부 예약 링크, 요금, 선착순 여부 |

이 4대 속성이 데이터 신뢰도 등급(`trust_tier`) 산정의 핵심 기준이기도 하다 — 상세는 [04-data-pipeline-and-quality.md](./04-data-pipeline-and-quality.md).

## 7. 데이터 확보 전략

초기엔 운영팀이 수동으로 수집·정제해 등록한다(공공 API, 기관 사이트, 커뮤니티 소스). 이후 UGC(제보/리뷰/사진)로 확장한다. 데이터 row별 파이프라인 상태와 신뢰도 등급 설계는 [04-data-pipeline-and-quality.md](./04-data-pipeline-and-quality.md) 참고.

## 8. 수익 모델

MVP는 수익화 없이 성장을 우선한다. 향후 후보: 예약 중개 수수료, 프리미엄 구독, 브랜드 제휴. 구체적인 수익화 기능 제안은 [05-monetization-and-roadmap.md](./05-monetization-and-roadmap.md) 참고.

## 9. 로드맵 (MVP 이후)

- UGC: 스팟 제보, 리뷰/사진/평점
- 테마별 추천 에디토리얼
- 실시간 정보: 혼잡도, 날씨, 계절별 적합도
- 네이티브 앱
