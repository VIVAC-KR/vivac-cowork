# 공통 상태 (로딩 · 빈 · 에러)

> 이 문서는 화면 문서가 아니라 **여러 화면에 공통으로 적용되는 규칙**입니다. 라우트가 없으므로 화면별 기능 명세의 자기완결 요구(원칙 V 한정 규정)를 적용하지 않고, 각 화면 문서가 이 규칙을 참조합니다.
> 제품 정의·MVP 범위·데이터 정의는 [PRODUCT.md](../../product/PRODUCT.md)가 기준입니다. 구현 현황은 [STATUS.md](../../STATUS.md) §7입니다.

**목적** — 로딩·빈 결과·오류를 일관되게 처리한다.

**동작**


| 상태      | 처리          |
| ------- | ----------- |
| 최초 로딩   | 스켈레톤 카드     |
| 추가 로딩   | 목록 하단 로딩 표시 |
| 빈 결과    | 조건 변경을 안내   |
| 오류      | 원인 안내 + 재시도 |
| 필터 전환 중 | 직전 결과 유지    |


**확정 계약**


| 항목        | 값               |
| --------- | --------------- |
| 빈 결과 ≠ 오류 | 별개 화면으로 구분한다    |
| 결과 수 미확정  | 0이 아닌 `—`로 표시   |
| 커서 무효화    | 오류 화면 없이 자동 재조회 |


**수용 기준**

- 로딩 → 결과 전환에서 레이아웃이 밀리지 않는다
- 오류 화면에서 재시도가 가능하다
