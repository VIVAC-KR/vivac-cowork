# 홈

> 제품 정의·MVP 범위·데이터 정의는 [PRODUCT.md](../PRODUCT.md)가 기준이다. 구현 현황은 [STATUS.md](../STATUS.md) §7.

**목적** — 진입점. 검색으로 유도하고 큐레이션된 스팟을 노출한다.

**동작**

- 검색 바 → 검색 화면 이동
- 큐레이션 캐러셀 2종(추천 / 인기) — 카드 탭 시 상세로 이동

**확정 계약**


| 항목     | 값                |
| ------ | ---------------- |
| 캐러셀 소스 | 고정 그룹 식별자 2개로 조회 |
| 조회 건수  | 그룹당 10           |
| 렌더     | 서버 프리페치 후 하이드레이션 |


**수용 기준**

- 캐러셀 카드에서 상세로 이동한다
- 그룹 조회 실패 시 홈 전체가 깨지지 않는다
