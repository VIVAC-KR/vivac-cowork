# 공통 상태 (로딩 · 빈 · 에러)

> 제품 정의·MVP 범위·데이터 정의는 [PRODUCT.md](../PRODUCT.md)가 기준이다. 구현 현황은 [STATUS.md](../STATUS.md) §7.

**목적** — 로딩·빈 결과·오류를 일관되게 처리한다.

**동작**


| 상태      | 처리          |
| ------- | ----------- |
| 최초 로딩   | 스켈레톤 카드     |
| 추가 로딩   | 목록 하단 로딩 표시 |
| 빈 결과    | 조건 변경을 안내   |
| 오류      | 원인 안내 + 재시도 |
| 필터 전환 중 | 직전 결과 유지    |


**확정 계약**


| 항목        | 값               |
| --------- | --------------- |
| 빈 결과 ≠ 오류 | 별개 화면으로 구분한다    |
| 결과 수 미확정  | 0이 아닌 `—`로 표시   |
| 커서 무효화    | 오류 화면 없이 자동 재조회 |


**수용 기준**

- 로딩 → 결과 전환에서 레이아웃이 밀리지 않는다
- 오류 화면에서 재시도가 가능하다
